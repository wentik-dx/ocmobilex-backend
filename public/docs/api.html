01Basics & errors

Send JSON with Content-Type: application/json. The default body limit is 8 MiB of JSON text; individual routes set smaller caps. Empty bodies are treated as {}; arrays and primitives are rejected.

# success
{ "ok": true, "token": "base64url(payload).base64url(hmac)" }

# failure
{ "ok": false, "error": "title must be at least 5 characters" }
StatusMeaning
400Validation failed — bad field, type, enum or malformed JSON.
401Missing, invalid or expired token / account no longer exists.
403Wrong role, banned, muted, wrong password, read-only share.
404Unknown id, code, user or route.
405Method not allowed on that route.
409Conflict — username taken, last owner, message limit reached.
413Payload over the route's size limit.
429Rate limited — retry after the interval in the message.
500Unexpected server error (nothing throws out of a handler).

The global middleware converts /api/* 404/405 and non-JSON errors into {ok:false,error,…}, and never leaks an HTML error page.

02Authentication — four different credentials

HeaderWhat it isAccepted by
Authorization: Bearer <token>Stateless HMAC-SHA256 session token from register/login. Payload {u, exp}, TTL 30 days. Re-verified against the account on every request.OCMX API only.
X-Owner-Token: <secret>Deployment-level secret from Cloudflare. Constant-time compared with OWNER_TOKEN. Also accepted for owner-only routes as an alternative to an owner Bearer token.OCMX API only — owner routes + /api/seed.
X-AI-Token: <secret>Optional service token for automated moderation reports. The owner token also counts as a service token.OCMX API only — POST /api/moderation/report.
Authorization: Basic …HTTP Basic used by the local opencode serve running in Termux on the phone. It authenticates the app to its own local agent runtime — not to OCMX.Local opencode serve. Never accepted by OCMX.
Do not mix them up: sending Basic credentials to this backend will fail with 401 Missing Authorization: Bearer <token>. Never paste an owner token, AI token, session token or password into a bug report, shared chat, published HTML or profile field.

Roles are ranked user → mod → admin → owner. requireStaff accepts mod/admin/owner; requireOwner accepts the owner secret or an owner-role session. Muted and banned accounts are blocked from content creation.

03CORS & rate limits

CORS

Access-Control-Allow-Origin: *; methods GET, POST, PATCH, DELETE, OPTIONS; headers Content-Type, Authorization, X-Auth-Token, X-Owner-Token, X-AI-Token; preflight 204, max age 86400 s. CORS is added to static assets too.

Limit mechanics

KV fixed windows with a 60 s floor (expirationTtl). Best-effort: KV has no atomic increment and is eventually consistent across colos — these stop casual abuse, not a distributed attacker.

Route groupLimit
Register5 per 10 minutes per IP.
Login10 per minute per IP and 10 per minute per username.
Bug report1 per 3 minutes per IP and per account.
Idea submit1 per 3 minutes per IP and per account.
Share reply20 per minute per account.
Moderation report5 per minute per account (service reports skip this).

04Status & seed

GET/api/statuspublic

Writes and reads back a sys:health probe to verify the KV binding. Never returns secret values, only booleans.

{ "ok": true, "service": "ocmobilex-api", "version": "1.0.0",
  "time": "2026-11-19T12:00:00.000Z",
  "storage": { "binding": "OCMX", "status": "ok", "error": null },
  "secrets": { "OWNER_TOKEN": true, "OWNER_PASSWORD": true,
               "SESSION_SECRET": true, "AI_TOKEN": false },
  "endpoints": ["POST /api/account/registernew", "…"] }
POST/api/seedX-Owner-Token only

Idempotently creates the MrWentik owner using the configured OWNER_PASSWORD secret. Never resets an existing password; promotes an existing seed account to owner if needed. No body.

curl -X POST https://ocmobilex.pages.dev/api/seed \
  -H "X-Owner-Token: $OWNER_TOKEN"

# 201 { ok:true, created:true, usersBefore, user, message }
# 200 { ok:true, created:false, message:"Owner account already exists", user }

05Accounts

POST/api/account/registernewpublic

Body {username, password, confirmPassword}. Username 3–24 of A-Za-z0-9_, password 8–200 chars, confirmation must match. First account and mrwentik become owner.

curl -X POST https://ocmobilex.pages.dev/api/account/registernew \
  -H 'Content-Type: application/json' \
  -d '{"username":"Wentik","password":"********","confirmPassword":"********"}'

# 201 { ok:true, token, user: publicUser(self:true) }
POST/api/account/loginpublic

Body {username, password}. Generic 401 for unknown user or wrong password; 403 if banned. Returns a fresh 30-day token.

{ "ok": true, "token": "…", "user": { "username": "Wentik", "role": "user",
    "bio": "", "color": "", "avatar": "", "links": {…},
    "joinedAt": "…", "stats": {"sharedChats":0,"published":0,"ideas":0},
    "mutedUntil": null, "banned": false } }
GET/api/account/mebearer

Returns {ok:true, user} with self and (for staff) moderation flags. Never includes password hash or salt.

PATCH/api/account/profilebearer

Only present fields change. Body limit 256 KB.

FieldRules
bioString, max 280 chars.
colorHex #RGB / #RRGGBB / #RRGGBBAA or a CSS colour name.
avatarHTTPS URL or data:image/(png|jpeg|jpg|webp|gif);base64,… up to ~180 KB; >180 KB → 413.
linksObject with github, site / website (alias), telegram; bare hosts get https://, @handle becomes https://t.me/handle. null resets.
 
curl -X PATCH https://ocmobilex.pages.dev/api/account/profile \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"bio":"Building OCMobileX.","color":"#7c3aed",
       "links":{"github":"github.com/Wentik","telegram":"@Wentik"}}'
# 200 { ok:true, user }
POST/api/account/deletebearer

Three confirmations: correct current password, matching confirmPassword, and literal confirmText: "DELETE". Removes votes, the vote index and the account record — which revokes all tokens.

{ "ok": true, "deleted": true, "username": "Wentik",
  "message": "Account deleted. All issued session tokens are now invalid." }
POST/api/account/roleowner

Accepts X-Owner-Token or an owner-role Bearer token. Body {username, role, banned?} where role is user|mod|admin|owner. The last owner cannot be demoted or banned; nobody can ban themselves; non-owners cannot touch the owner role.

# 200 { ok:true, user: publicUser(staff:true) }

06Users

GET/api/users/:usernamepublic

Public profile; optional Bearer token upgrades the view for staff (flags, mutedUntil). Leading @ is stripped; lookups are case-insensitive via user:<lowercase>.

curl https://ocmobilex.pages.dev/api/users/MrWentik
# 200 { ok:true, user:{ username, role, bio, color, avatar, links, joinedAt,
#                       stats:{sharedChats,published,ideas} }, staffView:false }

07Bug reports

POST/api/bugreport/sendpublic · optional bearer

Body limit 256 KB. Required title (5–100). Optional version (40), steps (5000), expected/actual (2000), device/contact (200), logs (20000), severity low|normal|high|critical (default normal). A Bearer token attributes the report; without one it stays anonymous.

# 201 { ok:true, id, createdAt, status:"open" }
GET/api/bugreport/getallreportsowner

Query ?status=&limit=25&cursor=. Sorted newest first; capped at 1000 scanned reports; cursor is opaque base64url.

# 200 { ok:true, reports:[…], total, nextCursor,
#        filters:{status:"open"|null, limit} }
POST/api/bugreport/updatestatusowner

Body {id, status, note?}. Status one of open, triaged, in_progress, resolved, wontfix, duplicate. Each change appends to report.history with from/to/note/by/at.

# 200 { ok:true, report }

08Ideas

POST/api/suggestidea/sendpublic · optional bearer

Body limit 64 KB. title 5–100, description ≤5000, category feature|design|performance|other (default feature), impact low|normal|high (default normal).

# 201 { ok:true, id, createdAt, idea:{id,title,description,category,impact,
#        votes:0,score:0,status:"open",author,createdAt,updatedAt} }
GET/api/suggestidea/getallideaspublic

Query ?status=&limit=25&cursor=&sort=votes|new (default votes). Anonymous callers get id/title/description/category/impact/votes/status/createdAt; staff additionally get author and updatedAt, plus canModerate:true.

# 200 { ok:true, ideas:[…], total, nextCursor, canModerate:false }
POST/api/suggestidea/votebearer

Body {id, dir:1|-1}. Same direction again removes the vote; opposite direction switches it. votes and score are kept in sync and clamped at zero.

# 200 { ok:true, id, votes, myVote:1|0|-1 }

09Sharing chats

POST/api/share/chatbearer

Body limit 6 MiB. title (1–120), optional sessionId (120), messages[] up to 2000 with roles user|assistant|system|tool and text ≤20000, plus permissions with five booleans (all default false): write, pin, editSession, deleteMessages, invite.

curl -X POST https://ocmobilex.pages.dev/api/share/chat \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"title":"Why is my build failing?","sessionId":"ses_abc123",
       "messages":[{"role":"user","text":"vite build fails","ts":1767200000000}],
       "permissions":{"write":true,"invite":false}}'

# 201 { ok:true, code:"…32 chars…",
#        url:"https://ocmobilex.pages.dev/shared/chat/<code>",
#        share:{code,title,sessionId,permissions,owner,createdAt,messageCount} }
GET/api/shared/chat/:codepublic

Code must match [A-Za-z0-9]{8,64}. A best-effort view counter is bumped via waitUntil.

# 200 { ok:true, chat:{code,title,sessionId,messages,permissions,owner,
#        createdAt,updatedAt,messageCount}, canWrite:true|false }
POST/api/shared/chat/:codebearer

Append a reply. Requires permissions.write (else 403), 20 posts/minute per account, body {text} ≤20000 chars, max 2000 messages (else 409). Appended message carries role:"user", author and ts.

# 201 { ok:true, message:{role,text,ts,author}, messageCount }

10Publishing

POST/api/publishbearer

Body limit 8 MiB. type html|image|music, title 1–120, optional description ≤2000 and tags (≤20 items, ≤32 chars each). data is a non-empty string; encoding defaults to text for html and base64 for image/music; mime defaults to text/html; charset=utf-8, image/png, audio/mpeg. Base64 data URLs are accepted.

Limits are measured on the decoded payload: HTML 512 KB, image 5 MB, music 5 MB (413 with code:"too_large"). Published HTML is served with a CSP sandbox so it cannot touch the site's origin storage.
curl -X POST https://ocmobilex.pages.dev/api/publish \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"type":"html","title":"Demo","data":"<!doctype html><h1>Hi</h1>"}'

# 201 { ok:true, id:"…16 chars…", url:"/p/<id>",
#        absoluteUrl:"https://ocmobilex.pages.dev/p/<id>",
#        type,title,size,mime,createdAt }
GET/api/publishedpublic

Query ?type=html|image|music&author=&limit=25&cursor=. Metadata only — never the payload.

# 200 { ok:true, items:[{id,type,title,description,tags,author,size,mime,
#        createdAt,url:"/p/<id>"}], total, nextCursor,
#        filters:{type:null,author:null} }
GET/api/published/:idpublic

Id must match [A-Za-z0-9]{4,64}. Single item including data and encoding.

# 200 { ok:true, item:{id,type,title,description,tags,author,data,encoding,
#        mime,size,createdAt,url:"/p/<id>"} }

11Moderation

POST/api/moderation/reportbeareror X-AI-Token

Body limit 64 KB. targetUsername 1–24 (must exist), reason 3–200, optional details/evidence ≤5000, source ai|user (defaults to ai for service callers). Users are limited to 5/minute; service reports skip the limit. Increments the target's reports counter.

# 201 { ok:true, id, createdAt, status:"open" }
GET/api/moderation/reportsstaff

Query ?status=open&limit=25&cursor=. Returns {ok,reports,total,nextCursor}.

POST/api/moderation/reportsstaff

Body {id, action, note?, contentId?, contentType?, durationHours?}. Actions: dismiss, warn, mute, ban, delete. contentType is share|publish|idea; durationHours clamps to 1–720 (default 24). Owners cannot be banned from this route. Re-applying an action sets reopenedAt.

curl -X POST https://ocmobilex.pages.dev/api/moderation/reports \
  -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' \
  -d '{"id":"REPORT_ID","action":"mute","durationHours":24,"note":"cool-off"}'

# 200 { ok:true, report, applied:"muted for 24h", deletedContent:null }
