What is this

A dependency-free JSON backend for the OCMobileX Android client. Plain ES-module Pages Functions, WebCrypto for passwords and sessions, a single KV namespace for storage. Every response is JSON with a boolean ok.

AccountsPBKDF2-SHA256 passwords, HMAC session tokens, roles, profiles.
Sharing32-char share codes with per-chat write / pin / invite permissions.
PublishingHTML, images and audio up to 5 MB, served at /p/<id>.
ModerationUser and AI reports, warn / mute / ban / delete actions.
FeedbackBug tracker with severity and logs, idea board with voting.
LegalToS and Privacy Policy served as markdown from the API.

Quick start

# health
curl https://ocmobilex.pages.dev/api/status

# register
curl -X POST https://ocmobilex.pages.dev/api/account/registernew \
  -H 'Content-Type: application/json' \
  -d '{"username":"MrWentik","password":"********","confirmPassword":"********"}'

# who am I
curl https://ocmobilex.pages.dev/api/account/me -H "Authorization: Bearer $TOKEN"
